# 🏏 MANCHI FEST 2026 - Tips & Tricks Guide

## Power User Tips

### Auction Management

#### Speed Up Bidding
- Use **keyboard shortcuts** instead of clicking:
  - Press **Space** repeatedly for quick +50 increments
  - Press **Backspace** to quickly reduce bid
  - Press **Enter** to instantly mark SOLD
- Pre-calculate bid amounts mentally to streamline process

#### Efficient Team Selection
- Click team buttons in sequence as they bid
- Last clicked team is the current highest bidder
- Displays in center panel "HIGHEST BIDDER"

#### Timer Management
- Use **Pause** button to discuss close bids
- **Resume** quickly when ready to continue
- Timer runs down from 60s for each player

#### Price Editing
- Click directly on the "Current Bid" number field
- Type new price for instant updates
- Useful for correcting mistakes quickly

### Data Management

#### Backup Your Tournament
Before deleting or resetting, always:
1. Go to sidebar (or click hamburger menu)
2. Click "Export JSON" to save complete backup
3. Save file safely on your computer
4. Later, you can manually restore by copying localStorage values

#### Regular Exports
- Export CSV after every 5-10 auctions for safety
- HTML export useful for projector display
- JSON export is the most comprehensive backup

#### Export to Spreadsheet
- Export CSV format
- Open in Excel/Google Sheets
- Create additional analysis sheets
- Merge with other tournament data

### Team Management

#### Quick Balance Check
- Team cards show current balance
- Green number = remaining budget
- Updated instantly after each sale
- No refresh needed

#### Player Tracking
- Click team card to expand and view all players
- See exact price paid for each player
- Useful for disputes or verification

#### Budget Warnings
- Watch remaining balance in team selector
- Sale will fail if insufficient balance
- Plan ahead for high-value players

### Analytics & Reporting

#### Best Performing Teams

#### Value Metrics

#### Transaction Analysis
- Use History filters to analyze patterns
- Filter by team to see spending habits
- Sort by price to find outliers

### Advanced Techniques

#### Keyboard-Only Operation
You can run the entire auction using only keyboard:
1. **Tab** - Navigate between inputs
2. **Space** - Increase bid
3. **Backspace** - Decrease bid
4. **Enter** - Mark SOLD
5. **Arrow keys** - Navigate dropdowns

#### Rapid Auction Workflow
1. Type player name + price
2. Press Enter (starts auction)
3. Press Space multiple times (bid increases)
4. Press Tab to select team
5. Press Enter (completes sale)
6. Repeat with next player

#### Multi-Monitor Setup
- Use one monitor for auction panel
- Use second monitor for leaderboard/statistics
- Arrange windows side by side
- Real-time stats visibility

### Troubleshooting Tips

#### Bid Stuck at Base Price
- Ensure timer is RUNNING (not paused)
- Check bid isn't already at higher value
- Try decreasing first, then increasing
- Reset auction if stuck

#### Team Selection Not Working
- Click team button to select
- Should highlight with green border
- Try clicking again if no response
- Refresh if persistent

#### Data Not Saving
- Verify localStorage is enabled in browser
- Check browser isn't in Private/Incognito mode
- Try different browser if issue persists
- Use Export as backup

#### Timer Running Too Fast/Slow
- This is browser dependent
- Close other applications for stability
- Hard refresh page if behavior changes
- Timer accuracy not critical for auction

### Performance Optimization

#### For Slow Devices

#### Battery Optimization (Mobile)

### Pro Strategies

#### Auction Speed Control
- For high-value players: Take time, let bids accumulate
- For lower-value players: Move quickly
- Use timer strategically
- Pause for major decisions

#### Bid Increment Strategy
- Early bids: +1000 increments (fast)
- Mid-range: +500 increments (balanced)
- Final bids: +100 increments (precise)
- Prevents premature auction ending

#### Team Psychology
- Watch team behavior patterns
- Note which teams bid aggressively
- Track their remaining budgets
- Adjust auction pace accordingly
